LAN Chat — мессенджер для компьютеров в одной Wi-Fi сети
=========================================================

Скачать последнюю версию: вкладка Releases (справа на странице репозитория).

  Windows — LANChat-Setup.exe: запустите и нажмите «Установить».
            Установщик сам добавит Microsoft WebView2, если его нет.
  Mac     — LANChat-mac.zip: распакуйте, перетащите LANChat.app в «Программы».
            Первый запуск: Системные настройки -> Конфиденциальность и
            безопасность -> «Всё равно открыть»
            (или в Терминале: xattr -cr /Applications/LANChat.app)

Если программа не запускается, подробности ошибки сохраняются в файле
.lanchat_error.log в папке пользователя.

Сборка: GitHub Actions собирает обе версии при каждом изменении.
Обновление: меню ⋯ -> «Проверить обновления» (программа также проверяет сама раз в 6 часов).
Запуск из исходника: pip install pywebview certifi, затем python lanchat.py
